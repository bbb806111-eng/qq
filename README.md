# 无限画布分镜工具（Storyboard Infinity Canvas）

一个纯前端原型：可在无限画布上组织分镜卡片、图片卡片、视频卡片，并支持平移缩放与 JSON 导入导出。

## 使用方式

直接在浏览器中打开 `index.html`，或运行本地静态服务器：

```bash
python3 -m http.server 4173
```

然后访问 `http://localhost:4173`。

## 已实现能力

- 无限画布：拖拽空白区域平移，滚轮缩放。
- 卡片类型：分镜 / 图片 / 视频。
- 卡片编辑：标题与描述可直接编辑，支持拖拽布局。
- 资源挂载：双击卡片资源区，粘贴图片或视频 URL 进行预览。
- 流程连线：按卡片横向位置自动绘制连接曲线。
- 数据流转：导入/导出 JSON。
